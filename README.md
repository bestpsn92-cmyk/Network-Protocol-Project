# Network Protocol Project

## Network Protocol Assignment Project

### Project Overview
This project demonstrates a basic DNS-like client-server communication system using Python and UDP sockets.

### Project Files
- `dns_server.py` – DNS server program.
- `dns_client.py` – DNS client program used to send domain name requests and receive responses.

### Technologies Used
- Python
- UDP Socket Programming
- Client-Server Communication

### How to Run
1. Run `dns_server.py` first to start the server.
2. Run `dns_client.py`.
3. Enter a domain name when prompted by the client.
4. The client sends the request to the server and displays the server response.

### Purpose
The purpose of this project is to demonstrate communication between a client and a server using UDP socket programming.
